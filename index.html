在本次測驗條件下，當兩個顏色的差異接近此數值時，你開始較難穩定辨認它們。數值越低，代表能辨認越細微的色彩差異。

這不是一般人平均值或排名，而是依照本次測驗條件估計的操作性數值。

這個數字怎麼來的？ ＋

ΔE00 是 CIEDE2000 色差公式的結果，用來描述兩個顏色的感知差異；單獨寫作 ΔE 並不能指定使用哪一種色差公式。

  1. 每題依照目前的 ΔE00 生成一組色差，並以同一個 session base color 維持測驗條件一致。
  2. 連續答對 2 題時降低 ΔE00；答錯或逾時時提高 ΔE00，形成 2-down / 1-up adaptive staircase。
  3. 記錄難度調整方向改變的 reversal，並以 reversal 的 actual ΔE00 中位數估計閾值。

這個估計約追蹤本遊戲條件下接近 70.7% 正確率的區域，不是臨床測量值，也不代表一般人口常模。
